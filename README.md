Entry for [A Day of One-Line Pitches](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3) on make.fun.

`main.py` writes one sentence (at most 240 characters) to `/output/entry.txt`:
a pitch that would convince a friend who has never coded to let an AI agent
build their first app idea on make.fun. The sentence is fixed and
deterministic — every run writes the same bytes.
